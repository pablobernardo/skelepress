# Visual check

Before operating the machine, locate the indicator panel. The original SVG below
is authored in this repository, not downloaded or generated by Mermaid. Its
three labelled positions remain distinguishable without relying on colour.

![Indicator panel][indicator-panel]{width=70%}

[indicator-panel]: indicator.svg

The image reference uses only the basename `indicator.svg`. The manual declares
`media` in `pandoc.resource_path`, so Pandoc finds the consumer-owned figure even
when the command runs outside this directory.

## A visible consumer filter

[Inspect the indicator before operation.]{.operator-check}

The source phrase is "Inspect the indicator before operation." The manual's
consumer-owned Lua filter adds the bold prefix **CHECK:** only to spans marked
with the `operator-check` class. Look for that prefix on the instruction above:
this is the named visible effect, not a built-in toolkit transformation.

[Ordinary text stays unchanged.]{.ordinary-note}

The filter lives in `mark-check.lua` and is registered through
`filters.extra_lua_filters`. Removing that registration leaves the original
instruction without its prefix. Both the figure and the filter belong to this
consumer example; neither requires a toolkit contract change.
